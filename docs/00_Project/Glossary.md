# Glossary

| Term | Definition |
|------|------------|
| Agent | A specialised software component responsible for one business capability. |
| AI Agent | An agent that performs reasoning or contextual interpretation using AI models. |
| Broker Adapter | The abstraction layer responsible for integrating Sigmatics with brokerage platforms such as Zerodha Kite. |
| Confidence | A quantified measure of supporting evidence behind a recommendation. It is not a probability of success. |
| Decision Contract | The immutable object representing a complete trading or investment recommendation. |
| Decision Snapshot | A persisted record containing the market state, recommendation and reasoning at a specific point in time. |
| Explainability | The ability to describe why a recommendation was produced. |
| Evolution | Controlled deployment of validated improvements into production. |
| Learning | Observation and analysis of historical decisions without modifying production behaviour. |
| Market Context | External and internal conditions that influence the interpretation of market signals. |
| Portfolio Intelligence | AI-assisted analysis and optimisation of investment holdings. |
| Product Principle | A constitutional rule governing product behaviour. |
| Engineering Principle | A constitutional rule governing software design and implementation. |
| Recommendation | A suggested action generated by Sigmatics, such as BUY, SELL, HOLD or WAIT. |
| Replay | Reproducing a historical recommendation using identical inputs to validate deterministic behaviour. |
| Signal | A measurable market observation derived from one or more quantitative indicators. |
| Trade Execution | User-approved submission of an order to a connected brokerage platform. |
| Trading Intelligence | The capability responsible for identifying and evaluating trading opportunities. |
| Financial Intelligence | Reporting, analytics and performance insights derived from trading and portfolio data. |
