# AGT-012 — Learning Agent

## Purpose

Observe completed decisions and learn from historical outcomes without influencing production behaviour.

---

## Business Responsibility

Generate learning insights and hypotheses.

---

## Inputs

- Historical Decisions
- Trade Outcomes
- Portfolio Outcomes

---

## Produces

- Learning Report

---

## Never Responsible For

- Live recommendations
- Strategy modification
- Production configuration

---

## Success Criteria

Generate measurable learning artefacts.

Maintain complete separation from production.
